## Community Contributors

We appreciate all contributions, whether code, documentation, bug reports, or feature ideas. Contributors are listed here in recognition of their support.

### How to Get Recognized

If you contribute to Aurora, you'll be automatically recognized in:
1. GitHub repository contributors list
2. This RECOGNITION.md file
3. Release notes for the version containing your contribution
4. Project documentation

### Contributing Areas

Aurora welcomes contributions in these areas:

- **Code** - Components, bug fixes, performance improvements
- **Documentation** - API docs, tutorials, guides
- **Design** - Icons, themes, visual enhancements
- **Accessibility** - WCAG AAA compliance, inclusive design
- **Testing** - Test coverage, bug reports, quality assurance
- **Community** - Support, discussions, mentoring

See [CONTRIBUTING.md](CONTRIBUTING.md) for detailed guidelines.

## Becoming a Contributor

Everyone is welcome to contribute to Aurora. Here's how to get started:

1. Read [CONTRIBUTING.md](CONTRIBUTING.md)
2. Check [Issues](https://github.com/Mullassery/aurora/issues) for opportunities
3. Join [Discussions](https://github.com/Mullassery/aurora/discussions) to ask questions
4. Submit a pull request with your changes

All contributions, no matter how small, are valuable and appreciated.

## Support Aurora

If you find Aurora useful, please consider:

- Starring the repository on GitHub
- Sharing Aurora with others
- Using Aurora in your GNOME applications
- Contributing code, documentation, or ideas
- Reporting bugs and suggesting improvements
- Supporting the maintainer through sponsorship
